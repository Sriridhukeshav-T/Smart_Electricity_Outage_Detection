Java PriorityQueue Engine

Deterministic Restoration Ranking Policy

Restoration jobs are dynamically ordered by the Java RestorationPolicy Comparator strictly using:

1
Critical Facilities Affected

Lifeline services (Hospitals, Water Works, Police) prioritized highest.

2
Total Affected Consumers

When critical count is tied, higher population density is prioritized.

3
Earlier Fault Report Order (FIFO)

When impact metrics are identical, the earlier fault is served first.
